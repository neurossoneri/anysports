# Запуск как настоящего сайта: хостинг, домен, что подготовить

Цены ниже ориентировочные (собраны в октябре 2026 из открытых источников). Перед покупкой проверьте их на сайте провайдера.

## Что именно размещается

- Размещается только папка `_site/`: готовые HTML, CSS, фото и страница `/admin/`. Ни базы данных, ни PHP, ни Python на хостинге не нужны.
- `_site/` собирает GitHub Actions из репозитория. **Репозиторий на GitHub остаётся главным местом хранения в любом варианте**: панель `/admin/` сохраняет правки в него.
- Цепочка: правка в панели → коммит в GitHub → Actions собирает сайт → выкладывает на хостинг.

## Этап 1 (сейчас): GitHub Pages + собственный домен

Бесплатно, уже работает с панелью. Нужно только купить домен (около 10–15 € в год) и указать его в Settings → Pages → Custom domain. HTTPS включается там же. В поле «Адрес сайта» панели укажите `https://ваш-домен/`.
Минус: серверы в США (GitHub/Microsoft). Для сайта о личной работе с людьми многие предпочитают европейский хостинг.

## Этап 2: европейский хостинг (простой и недорогой)

| Вариант | Страна | Ориентир по цене | Когда подходит |
|---|---|---|---|
| **Hetzner Webhosting** | Германия | от ~2 €/мес (тариф S) | Самый простой и дешёвый «классический» вариант: загрузка по SFTP/FTPS, свои почтовые ящики на домене, PHP (можно сделать форму связи, которая тоже остаётся в ЕС). Проверьте, есть ли разовая плата за подключение. |
| **Infomaniak** | Швейцария (не ЕС, но с надёжной защитой данных) | от ~8–11 CHF/мес за веб-хостинг; у них же есть совсем простой тариф для одностраничников | Сильная репутация по приватности, интерфейс и поддержка на французском. Дороже Hetzner. |
| **bunny.net** (хранилище + CDN) | Словения | минимум $1/мес, далее ~$0.01 за ГБ хранения и трафика в Европе | Самый быстрый и почти бесплатный для статики, но технически сложнее (нет почты, нет PHP). |
| IONOS (Германия), OVHcloud (Франция) | ЕС | в том же диапазоне | Запасные варианты. |

**Моя рекомендация:** Hetzner Webhosting, если нужна простота и цена, и вы хотите почту вида `hello@ваш-домен` и форму без сторонних сервисов. Infomaniak, если важнее французский интерфейс и швейцарская юрисдикция.

## Что подготовить до запуска

1. **Домен**: купить у регистратора (Hetzner, Infomaniak, INWX, Gandi). Имя вроде `sportintuitive.com` / `.eu`, проверьте, что оно свободно.
2. **Шрифты**: готово. Inter, Source Serif 4 и Caveat лежат в папке `fonts/` и отдаются с самого сайта, Google IP посетителя не получает.
3. **Форма связи**: сервисы вроде Formspree находятся в США. Варианты: ЕС-сервис форм либо собственный обработчик на PHP на европейском хостинге (письма остаются в ЕС).
4. **Юридические страницы**: для сайта из Германии обычно нужны выходные данные (Impressum) и политика конфиденциальности. Я не юрист: уточните у юриста или на сервисах-генераторах для вашей ситуации.
5. **Фото**: заменить на файлы без водяных знаков, подтвердить права на публикацию.
6. **Заполнить**: имя, специализация, контакты (email, форма), подтвердить пункты из `docs/CONTENT-REVIEW.md`.
7. **Включить индексацию** галочкой на вкладке «Публикация» только после всего выше.
8. **Закрыть `/admin/`** (по желанию) на хостинге паролем (`.htaccess`): токен и так нужен, но это второй замок.

## Как выглядит переезд на европейский хостинг

1. Купить хостинг и домен, направить домен на хостинг (записи DNS).
2. Добавить в репозиторий секреты (адрес, логин, ключ SFTP) и ещё один шаг в `.github/workflows/deploy.yml`, который после сборки загружает `_site/` на хостинг.
3. В поле «Адрес сайта» панели указать новый домен.
4. Проверить: сайт, форму, `/admin/` (панель продолжит сохранять правки в GitHub), отправить тестовое письмо.
5. Отключить GitHub Pages.

Шаг 2 зависит от выбранного хостинга; когда решите, я подготовлю готовый workflow под него.
